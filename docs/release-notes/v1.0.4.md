# Release v1.0.4

v1.0.4 is a focused fix and quality-of-life release. The headline changes are a
**bg exporter reference regression fix** (42,676 edges silently dropped in
v1.0.3's performance rewrite), a **Freeze Viewport** toggle for easier node
inspection on busy graphs, **baseline features** (Config Data, Path Finder,
Schema Diff always on), and a full **guide documentation refresh**.

## Bug fixes

### bg exporter reference regression ([#211](https://github.com/revampd/sn-schema-explorer/issues/211))

The O(1) lookup introduced by the v1.0.3 performance rewrite always returned
`undefined` on real ServiceNow instances, silently dropping all 42,676 reference
edges (`references: 42676 → 0`). Root cause: `sys_dictionary.reference` can
store either the target table's `sys_id` or its name depending on the SN
version, and Rhino's Java/JS string coercion meant even matching keys failed
strict equality.

Fix: dual lookup map (`dbObjectById` for sys_id keys + `dbObjectByName` for name
keys) with explicit `String()` coercion on every lookup. Verified byte-for-byte
identical schema output against the pre-regression baseline (1 byte diff —
timestamp only). Performance is unchanged: ~185 s on a 9,356-table instance.

## What's new

### Freeze viewport ([#213](https://github.com/revampd/sn-schema-explorer/issues/213))

A **⊘** button appears in the zoom controls (also **Shift+L**). While active,
clicking visible nodes updates the inspector without recalculating the
neighbourhood or repositioning the graph — useful when inspecting many nodes on
a dense canvas. Pan and zoom continue to work normally. Click ⊘ again (or press
Shift+L) to unfreeze.

## Changes

### Baseline features ([#216](https://github.com/revampd/sn-schema-explorer/issues/216))

**Config Data, Path Finder, Schema Diff, and Advanced Path Finder** are now
always enabled and hidden from the Settings modal. These features have been
stable for several releases; making them optional added friction without benefit.
Existing per-user preferences in `localStorage` are ignored for baselined
features — `isEnabled()` always returns `true`.

**Max PNG Scale** is removed from the Settings UI. The setting and its storage
key remain functional (export module still reads and writes it), but the stepper
control is no longer shown — the detected canvas limit is the right default for
virtually all users.

### Guide refresh

All guide tabs updated to reflect v1.0.3 and v1.0.4 changes: export wizard
flow (replaced accordion), baselined features (removed "Enable in Settings"
instructions), Freeze Viewport card in the navigation guide, inspector diff
sections expanded for multi-compare and config layers, stats bar moved to header,
footer card updated.
