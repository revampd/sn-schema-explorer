# Release v1.0.2

This release is a hardening, testing, and quality pass over the v1.0.2 milestone:
a full repository audit ([#50](https://github.com/revampd/sn-schema-explorer/issues/50)),
a large internal refactor with zero behaviour change
([#73](https://github.com/revampd/sn-schema-explorer/issues/73)), and a batch of
bug-fixes and small enhancements
([#89](https://github.com/revampd/sn-schema-explorer/issues/89)). It also tightens
secret handling in the Node extractor — see **Breaking changes** below.

## ⚠ Breaking changes

- **The Node extractor no longer accepts credentials as command-line arguments.**
  Passing `--password` or `--apikey` now exits with an error — these leak into
  shell history and process listings. Provide secrets via the `SN_PASSWORD` /
  `SN_APIKEY` environment variables instead.

## What's new

### Optional edge-type legend in image exports (#89)

A toggle in the Export menu (next to ↓ SVG) embeds the edge-type legend into your
PNG and SVG exports. It shows **only the edge types currently drawn** on the
canvas — toggled-off types are omitted — so the legend always matches the image.
Off by default; your choice is remembered.

### Table Access filter condition (#41)

The advanced filter builder gains a **Table Access** condition
(`package_private` / `public`), so you can narrow the canvas by a table's
cross-scope accessibility.

### Optional update check (#45)

Once per session, a dismissible footer badge links to a newer GitHub release when
one is available. It can be turned off in Settings, and the only network call is a
single GET to the public releases API — no telemetry.

## Improvements

### Path Finder

- **Hop exclusions moved above the _Find shortest path_ button** — exclusions
  constrain the search, so they now sit with the inputs that drive it (#89).
- **Sidebar scrollbar** is now styled to match the app's other custom scrollbars
  (#89).

### Background Script exporter

- **JSON split thresholds lowered to 10 MB** — both the single-attachment trigger
  and the per-part size. This caps peak in-memory string size and avoids memory
  pressure on large exports inside ServiceNow's Rhino engine (#89).
- User-supplied record-count regex patterns are compiled defensively: an invalid
  pattern is skipped with a warning instead of aborting the whole export.
- `sys_dictionary` is queried with `active!=false` to match the Node extractor, so
  both exporters return the same set of rows.

### Saved Views & Guide

- Saved-view naming and "Open in ServiceNow" now use an inline modal input instead
  of the blocking `window.prompt()` (suppressed by some browser-hardening
  policies); "Open in ServiceNow" opens directly when the instance is known from
  the loaded schema (#46).
- The in-app guide was corrected to match the implementation — filter conditions,
  AND/OR connectors, the operator cycle, and the Export/Filter controls (#48).

## Bug fixes

- **Path Finder no longer returns stale results after a Schema Diff comparison** —
  its adjacency cache is now invalidated when the graph is re-indexed.
- **Node extractor**: pagination has a safety cap (no infinite loop on
  misbehaving/duplicate pages) and HTTP responses are size-capped to avoid heap
  exhaustion.
- **Viewer robustness**: `filterOk` is memoised; `localStorage` write failures
  warn instead of failing silently; a canvas label-truncation off-by-one is fixed;
  zoom-time indicator updates read from the simulation instead of re-scanning the
  DOM; the filter "+ Add condition" picker and autocomplete dropdowns are
  body-portalled so they can't be clipped.
- **`build.js app`** fails with a clear message when the exporter `dist/` files are
  missing, instead of an opaque `ENOENT`.

## Security

- Schema-derived values in the density-info line and the Schema Diff list are now
  escaped (previously interpolated into `innerHTML`), preventing script execution
  from a maliciously crafted schema file (#46).

## Removed

- The non-functional "Expand references" canvas context-menu item (#49).

## Infrastructure & quality

- **Internal refactor with zero behaviour change** (#73): large source files were
  split into cohesive modules and CSS partials — the viewer/Node/Background export
  serialisers, Path Finder config and hop-exclusion UI, the advanced-filter
  evaluation core, the Schema Diff inspector, the render instance-info pill/modal,
  and the two large stylesheets. The built outputs are byte-for-byte unchanged.
- **Linting & formatting**: ESLint (flat config) and Prettier, with `lint`,
  `format`, `format:check`, and `test:coverage` npm scripts; `format:check` is
  enforced in CI.
- **Coverage**: vitest v8 coverage reporting with a ratcheted CI threshold.
- **CI**: lint job, `npm audit`, and a Node `[20, 22, 24]` test matrix; the release
  workflow runs lint + unit + build + e2e before publishing.
- **Tests**: extensive unit + e2e suites — Node extractor, export serialisers,
  state round-trip, pathfinding, schema builder, filter UI, the shared
  autocomplete, and e2e for export formats, Path Finder, and Schema Diff.
- `package.json` now declares `engines.node >= 20` for the dev toolchain (the
  standalone exporter artifact still runs on Node 18+).
