SN Schema Explorer is a free, open-source tool for visualising ServiceNow table schemas as an interactive graph. Everything runs in a single self-contained HTML file — no installation, no server, no external dependencies.

## Three builds are included

| File                            | Contents                                                                   |
| ------------------------------- | -------------------------------------------------------------------------- |
| `sn_schema_explorer_lite.html`  | Schema Map · Inspector · Export · Settings · Guide                         |
| `sn_schema_explorer.html`       | Everything in Lite + Path Finder + Schema Diff                             |
| `sn_schema_explorer_setup.html` | Everything in Full + embedded exporter scripts for self-service onboarding |

## Features

**Schema Map**

- Force-directed graph of your entire table schema — inheritance chains, reference fields, M2M relationships, CMDB CI topology
- Adjustable hop depth and max-node density controls
- Edge-type filters, scope filters, and application domain grouping
- Context menu, minimap, and saved view snapshots

**Inspector**

- Fields with types, max length, and reference targets
- Outgoing and incoming references, M2M links, DB views, CMDB CI relationships
- Full inheritance chain with ancestor navigation

**Path Finder** _(full build)_

- Finds the shortest dot-walk path between any two tables or to a specific field
- Useful for building encoded queries, ACL conditions, and GlideRecord scripts

**Schema Diff** _(full build)_

- Load two schema exports side-by-side and see exactly what tables and fields were added, removed, or changed
- Useful for upgrade impact analysis and release validation

**Export**

- PNG with a resolution slider (up to 200× on capable browsers) and a custom background colour/opacity picker
- SVG export
- Schema and neighbourhood export as JSON

## Exporters

Two ways to export your schema from ServiceNow:

- **Background Script** — run directly in Scripts - Background, no instance-side setup. Saves the output as an attachment on your user record. Recommended.
- **Node.js extractor** — runs locally, authenticates via Basic Auth or API key (`x-sn-apikey`). Requires Node.js 18+ and network access to your instance.

Both exporters are embedded in `sn_schema_explorer_setup.html` for easy self-service distribution.

## Requirements

- Any modern browser (Chrome, Firefox, Edge, Safari)
- A ServiceNow instance to export from (PDI or production)
- `admin` role for the Background Script exporter
