# Release v1.0.3

v1.0.3 is a major feature release built on top of the v1.0.2 hardening pass.
The headline additions are a **multi-instance landing page**, **Schema Diff as a
layer on the Schema Map**, a **Configuration Data tool** for cross-instance
reconciliation, **multi-compare support**, richer **exporter metadata**, and a
configurable **background-script setup UI**.

## What's new

### Landing page & multi-instance registry ([#101](https://github.com/revampd/sn-schema-explorer/issues/101), [#99](https://github.com/revampd/sn-schema-explorer/issues/99))

The app now opens on a landing page. Drop one or more schema exports to register
them as **instance cards** — each card shows the sections present in that export
and a row of per-instance tool icons. A **Home** button in the header returns to
the landing page from any tool. The backing store is a new
`core/instances-state.js` singleton with presence-based capability detection.

### Schema Diff as a layer on the Schema Map ([#141](https://github.com/revampd/sn-schema-explorer/issues/141))

Comparison is no longer a separate view. Pick a **Compare** instance from the
header dropdown and the structural diff (added/removed/changed colouring, edge
pills, and the change-report sidebar) activates **on the map** without leaving
it. The separate "Diff" view-mode is gone; the schema-map canvas is the diff
canvas.

### Multi-select Compare ([#150](https://github.com/revampd/sn-schema-explorer/issues/150), [#149](https://github.com/revampd/sn-schema-explorer/issues/149))

The header **Compare** control is now multi-select — tick multiple instances to
get an **N-column roll-up** in the sidebar and an **N-column comparison
inspector** that scales from one compare to many. A single compare keeps the
classic grouped list and pairwise inspector unchanged.

### Configuration Data tool ([#104](https://github.com/revampd/sn-schema-explorer/issues/104), [#103](https://github.com/revampd/sn-schema-explorer/issues/103), [#123](https://github.com/revampd/sn-schema-explorer/issues/123))

A new workspace that views and reconciles a metadata section — **plugins, store
apps, custom apps, or system properties** — across the instances you've
registered. Launch it from an instance card's **▦** icon (enable Configuration
Data in Settings). Status chips (`in sync` / `drift` / `missing` / `state
mismatch` / `inactive`), the store-app "↑ update" signal, an optional dates
column, and search + status filters. Exports as CSV or JSON.

### Config drift on the Schema Map & inspector ([#133](https://github.com/revampd/sn-schema-explorer/issues/133), [#139](https://github.com/revampd/sn-schema-explorer/issues/139))

- A toggleable **config-drift layer** tints schema-map tables by the drift
  status of the app that owns their scope.
- The **comparison inspector** gains a **Configuration** section showing owning
  app, version, and active state on each side, with a drift badge on drifted
  canvas nodes.

### Export the active comparison ([#177](https://github.com/revampd/sn-schema-explorer/issues/177))

While a comparison is active, the export bar gains comparison controls: fold the
diff into any full schema export, or export the **comparison only** as JSON /
Markdown / JSON-LD / OWL-Turtle / OpenAPI. PNG and SVG image exports carry the
on-canvas diff colouring; the **Legend** toggle now also draws a **Differences**
key into the image.

### Kind filter chips in the diff sidebar

A row of toggle chips slices the Added / Removed / Changed report by element
type — Fields, References, Inheritance, M2M, Named relationship, DB view, CI
topology. Only the kinds present in the current comparison get a chip. Summary
counts update as `passing/total`.

### Header tool switcher & instance dropdown ([#127](https://github.com/revampd/sn-schema-explorer/issues/127))

The header is reorganised around an always-visible **tool switcher** and a new
**instance dropdown** that switches the loaded instance in Schema Map / Path
Finder and sets the **Base** in Schema Diff. Move between tools and instances
without going Home.

### Cross-instance metadata in the export ([#97](https://github.com/revampd/sn-schema-explorer/issues/97), [#98](https://github.com/revampd/sn-schema-explorer/issues/98))

Both exporters gain optional metadata sections (plugins, store apps, custom
apps, system properties):

- **Node extractor**: `--metadata=plugins,storeApps,customApps,properties`
  (`SN_METADATA`). Property values off by default; `--include-property-values`
  opts in with a denylist. `--property-query` narrows which properties export.
- **Background script**: `CONFIG.metadataSections`, `includePropertyValues`,
  `propertyValueDenylist`, and `propertyEncodedQuery`.

Store apps gain `latestVersion`, `updateAvailable`, `installDate`, and
`updateDate`; plugins and custom apps gain dates.

### Configure the background script before copying ([#123](https://github.com/revampd/sn-schema-explorer/issues/123))

The setup instructions gain a form that rewrites the background exporter's
`CONFIG` block in place — output format, record counts, metadata sections,
property values, and edge types — so you copy a ready-configured script.

### App-themed custom dropdowns ([#126](https://github.com/revampd/sn-schema-explorer/issues/126))

All native `<select>` elements replaced with a keyboard-accessible ARIA listbox
dropdown. Used for the Schema Diff pickers, Configuration Data status filter,
advanced filter edge-type picker, and the bg-script output format picker.

## Improvements

- **Shared focus across lenses** ([#131](https://github.com/revampd/sn-schema-explorer/issues/131)) — the table selected in Schema Map carries into Path Finder's source when you switch tools.
- **Shared comparison context** ([#138](https://github.com/revampd/sn-schema-explorer/issues/138)) — one `compareId` shared across Schema Diff and Config Data.
- **Background exporter splits at 5 MB** (was 10 MB) — lowers peak in-memory string size in the Rhino sandbox; the viewer auto-stitches multi-part exports.
- **Export bar surfaces in every tool** — Schema Map keeps data + image rows; Path Finder shows image exports only; Configuration Data gains CSV / JSON.
- **All checkboxes migrated to toggle switches; all selects unified.**
- **Unified scrollbar theming** — single global rule replaces ~12 per-component rules.
- **Instance rename is now inline** — no `window.prompt()` popup.
- **Performance**: diff sidebar built once per comparison (not twice); element-kind set memoised per comparison; large diff groups (>200 tables) start collapsed with lazy row rendering.
- **About chip replaces footer credits** — `v1.x.x` chip opens an About modal with version, update status, and GitHub link.

## Bug fixes

- **Diff "Kind" filter labels no longer truncate** — menu widens to fit.
- **Diff "Kind" summary counts track the slice** and re-render on every change.
- **Comparison inspector no longer shows compare-only tables as "identical"** in the base column.
- **Starting a comparison no longer collapses the Schema Map** — shows the full graph with diff colouring by default.
- **Diff sidebar rows for compare-only tables are now clickable.**
- **Swapping/switching base no longer corrupts the comparison** — outgoing base is ungrafted before any switch.
- **Configuration Data: plugins were compared as all "missing"** — now keyed on name (stable `@scope/plugin` id) instead of sys_id.
- **Configuration Data: trailing instance columns scrolled off-screen** — values wrap/truncate with full value on hover.
- **Re-importing the same schema file no longer does nothing** — file input resets after each selection.
- **Advanced filter edge-type dropdown was clipped** — menu is now portalled to `<body>` with `position: fixed`.
- **Application Scope filter is usable on instances with many scopes** — pill list is height-capped and scrolls.
- **Inspector no longer crashes on a field without a label.**
- **Schema Diff no longer leaks compare-only tables into the Schema Map** after leaving diff view.
- **Background-script exporter failed to compile in ServiceNow** with `invalid property id` ([#120](https://github.com/revampd/sn-schema-explorer/issues/120)) — ES3-reserved words (`float`, `boolean`) are now quoted as object-literal keys.
