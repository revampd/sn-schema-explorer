Configuration Data

Reconcile plugins, store apps, custom apps, and system properties across the instances you've registered — to spot version drift, missing entries, and active-state mismatches between (for example) dev, test, and prod.

How to use it

1. Register two or more instances on the landing page whose exports include the metadata sections (run the exporter with the metadata options on).

2. Click the ▦ Compare instances icon on any instance card.

3. Pick a section tab (Plugins / Store apps / Custom apps / Properties). Each tab shows a column per instance that carries that section.

A section tab is disabled until at least two registered instances carry that section. If a tab is greyed out, re-export the relevant instances with that metadata section enabled.

Reading the table

In syncPresent in every instance with the same version and consistent active state.
DriftPresent everywhere but the version (or property value) differs.
MissingAbsent from at least one instance (shown as — in that column).
State mismatchSame version, but active in some instances and inactive in others.
InactivePresent with the same version but inactive everywhere.

A green dot marks active, a hollow red dot inactive. For store apps, a ↑ update marker flags update_available (with the latest version when known). Toggle Show dates to add install / update dates per cell — these are context only and never count as drift (they always differ across instances).

Export

Click Export CSV to download the current section's comparison — one row per entry with a column per instance per field and the reconciled status. Export JSON gives the same data structured for tooling: section, the compared instances, the comparable fields, status counts, and one entry per key with a per-instance cell.
