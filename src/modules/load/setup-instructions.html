Background Script · Step 3 of 3
Navigate to System Definition → Scripts - Background (or search "Scripts - Background" in the navigator). Make sure the application picker (top-right) shows Global. Paste the script below and click Run script. The script writes the output as a sys_attachment on your own user record and logs the download URL — open it from the result area to grab the file.

Expected runtime on a typical instance (~6800 tables): 45–90 seconds without record counts.

Background Script UI checklist:
  • Application scope picker — must show Global
  • Record for rollback? — leave checked (default). Creates a rollback context so the script can be rolled back via Script Execution History if anything goes wrong.
  • Execute in sandbox? — leave unchecked. Sandbox mode prevents data writes; the script needs to save the export as a sys_attachment.
  • Cancel after 4 hours? — leave checked (default). The script completes in under 2 minutes on most instances.
⚠ Requires the admin role. For non-admin environments use the Node.js extractor, or ask your ServiceNow administrator to run this script on your behalf.
