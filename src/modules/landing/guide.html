The landing page

The landing page is the front door. You register one or more instance exports, then pick a tool. Each instance advertises what it contains, and tools light up only when enough instances carry the data they need.

📄 Registering instances

Drop a schema_graph.json export onto the drop zone, or click to browse. Each load adds an instance to the list — drop several to compare across them.

Single file: the standard output from the Background Script or Node.js extractor.

Multi-part: large instances split into a manifest plus .part*.json chunks — select or drop them all together and the loader reassembles them.

Demo: click Load Demo Dataset to register a pre-built sample covering ITSM, CMDB, HR, CSM, Risk, and Asset tables.

Expand How to export a schema from ServiceNow for step-by-step guidance on running the exporter scripts. To capture plugins, store/custom apps, and system properties for cross-instance comparison, enable the metadata sections in the exporter.

🧰 Tools

Select an instance in the list, then click a tool tile. Schema Explorer visualises the selected instance. Other tools (e.g. Configuration Data) unlock once an instance carries the right data.

A disabled tile shows what it needs (for example, two instances with plugin data).

Returning to the landing page

Use the Home button in the header to come back here at any time — to register another instance or switch tools.
